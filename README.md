Chuleta de atajos para el entorno de clase [`entorno-nvim`](https://github.com/isaiasfl/entorno-nvim) del profesor Isaías Fernández Lozano: tmux, Neovim, snippets, explorador, Git/LazyGit y NPM.

**Verla online:** https://dromercode.github.io/chuleta-entorno-nvim/

También se puede abrir `index.html` directamente en el navegador: es un único archivo sin dependencias, con buscador y modo claro/oscuro automático.
