Atajos del entorno de clase de DWEC (entorno-nvim, el repositorio del profesor Isaías Fernández Lozano): tmux con Neovim, explorador de archivos, Git y NPM. Está en modo Básico: pulsa Todo arriba para ver también los atajos avanzados. El buscador siempre busca en todo.

Espacio→f→f

Pulsa y suelta cada tecla, una detrás de otra.

Ctrl+v

Mantén Ctrl y pulsa v a la vez.

Ctrl+a y Espacio

Ctrl+a manda en tmux (los paneles). Espacio manda en Neovim (el editor), en modo normal.

Primer día

En este orden, y ya puedes trabajar.

  1. Instálalo una vezCon el comando de una línea de Instalar. En Windows, dentro de Ubuntu (WSL2).
  2. Abre tu proyectocd a la carpeta del proyecto y escribe entorno-dev .
  3. Ubícate en la pantallaArriba el editor, abajo una terminal. Ctrl+a→t te lleva a la terminal y Ctrl+a→n te devuelve al editor.
  4. Escribe y guardai para escribir, Esc para parar, Espacio→w para guardar (también formatea).
  5. Sal sin perder nadaCtrl+a→d te saca y lo deja todo abierto. Mañana, entorno-dev . lo recupera tal cual.

Instalar, actualizar y abrir

Siempre en una terminal de Linux. En Windows, la de Ubuntu (WSL2), en tu carpeta ~ y nunca en /mnt/c ni en PowerShell.

Linux

# instalar (o actualizar si ya lo tienes) curl -fsSL https://raw.githubusercontent.com/isaiasfl/entorno-nvim/main/install.sh | bash

Windows 11 (WSL2)

# 1. en PowerShell como administrador (y reinicia) wsl --install -d Ubuntu # 2. dentro de Ubuntu, el mismo comando que en Linux curl -fsSL https://raw.githubusercontent.com/isaiasfl/entorno-nvim/main/install.sh | bash

Se instala en ~/entorno-nvim y al terminar abre una terminal nueva con entorno-dev listo. Ubuntu te pedirá un usuario y contraseña de Linux: no son los de Windows.

Cada día

# abrir un proyecto cd ~/ruta/de/mi-proyecto entorno-dev . # actualizar el entorno (guarda antes tu trabajo) cd ~/entorno-nvim ./scripts/actualizar.sh # si algo falla: copia el mensaje y mándaselo al profe ./scripts/instalar-alumno.sh --comprobar

Objetos de texto

i = dentro, a = alrededor (con los delimitadores). Se combinan con d borrar, c cambiar, y copiar o v seleccionar: ci{ cambia el contenido de un bloque, dap borra el párrafo. Si el cursor está antes, ci", ci(… saltan a los siguientes de la línea.

CombinaciónAcción
iw / awLa palabra / la palabra con el espacio siguiente
i" / a"Dentro de las comillas / incluyéndolas (también ' y `)
i{ / a{Dentro del bloque / con las llaves (también ( y [)
it / atContenido de una etiqueta HTML / la etiqueta entera (cit cambia el texto de dentro)
ia / aaUn argumento / con su coma: cia en suma(a, |b) deja suma(a, )
if / afLo de dentro de una llamada a función / la llamada entera
ip / apPárrafo / párrafo con la línea en blanco
Ctrl+v (en el editor)Selección rectangular (columnas)

Errores, ayuda y código

Los errores salen con una E o una W en el margen, subrayados y con el mensaje al final de la línea. La barra de abajo cuenta «Errores: 4 Avisos: 1». En HTML también avisa de atributos mal escritos, ids repetidos y cierres incorrectos.

Node, NPM y Vite (en la terminal de abajo)

# crear un proyecto Vite en la carpeta actual npm create vite@latest . # instalar dependencias y arrancar npm install npm run dev # ver versiones node --version npm --version

El ^ delante de una versión en package.json significa «esta versión o una posterior compatible». Para un archivo suelto .js o .ts basta con Espacio→r.

Git y LazyGit

Se abre con Espacio→g→g (o Ctrl+a→g). Encuentra el repositorio aunque esté en una subcarpeta. Las teclas cambian según el panel: si dudas, ?.
