Atajos del entorno de clase de DWEC (entorno-nvim, el repo del profesor Isaías Fernández Lozano): tmux con Neovim, explorador de archivos y flujo de Git/NPM.

No es LazyVim. Usa el gestor de plugins Lazy, y el menú de Espacio está organizado al estilo LazyVim, pero la configuración, los atajos y el explorador (NvimTree) son propios de este repositorio. Hay dos teclas líder: Ctrl+a para tmux y Espacio para Neovim. Los atajos con prefijo se pulsan en dos pasos, sin mantener nada pulsado.
Novedades del 7 de octubre (actualiza con ./scripts/actualizar.sh)
  • Búsquedas nuevas: Espacio→f→r recientes, w la palabra del cursor, d errores de todo el proyecto y . repetir la última búsqueda.
  • Rodear texto con comillas, paréntesis o etiquetas: sa añadir, sd quitar, sr cambiar.
  • Más bloques de texto: cia argumento, cif llamada a función. ci" salta solo a las siguientes comillas de la línea.
  • Git en el margen: marcas de líneas nuevas, cambiadas y borradas, ]h / [h para saltar entre cambios y Espacio→g→d para verlos.
  • Espacio→g→g encuentra el repositorio aunque esté en una subcarpeta, y ya no ofrece crear uno por error.
  • Snippets nuevos de DOM, fetch, arrays, tipos de TS y tests. La ayuda F1 empieza con un bloque «Lo imprescindible».

02

Instalar, actualizar y arrancar

En Windows, todo dentro de WSL2/Ubuntu y en tu carpeta ~, nunca en /mnt/c.

# primera vez (perfil único: web, React, Tailwind, Bash, Python y Docker) cd ~ git clone https://github.com/isaiasfl/entorno-nvim.git cd entorno-nvim ./scripts/instalar-alumno.sh # actualizar (guarda antes tu trabajo) cd ~/entorno-nvim ./scripts/actualizar.sh # si tu copia es antigua y no tiene actualizar.sh (solo una vez) git restore . && git pull --ff-only && sh scripts/actualizar.sh # abrir un proyecto cada día cd ~/ruta/de/mi-proyecto entorno-dev . # si algo falla: copia el mensaje y mándaselo al profe ./scripts/instalar-alumno.sh --comprobar
Opción de entorno-devUso
--iaAñade el panel de agente de IA
--sin-iaEditor y terminal sin panel de IA
--sin-tmuxAbre solo Neovim, sin tmux
--elegirSelector de proyectos conocidos

Ya no hace falta --perfil dwec: se acepta, pero instala lo mismo. Si reinstalas en otra carpeta, entorno-dev se redirige solo a la copia nueva.

Seleccionar y objetos de texto

i = dentro (contenido), a = alrededor (incluye los delimitadores). Se combinan con d (borrar), c (cambiar), y (copiar) o v (seleccionar): ciw cambia una palabra, ci{ cambia el contenido de un bloque, dap borra el párrafo entero.

CombinaciónAcción

> / < (visual)Aumentar / reducir sangría sin perder la selección

i" / a"Dentro de las comillas / incluyéndolas (también ' y `)
i{ / a{Dentro del bloque / incluyendo las llaves (también ( y [)

ci", ci(, cia… ya no exigen estar dentro: si el cursor está antes, saltan a las siguientes comillas, paréntesis o argumento de la línea.

09

Git y LazyGit

nuevo

Git en el margen

En los archivos de un repositorio, el margen marca lo que has cambiado desde el último commit: ▎ línea nueva, ▎ línea cambiada, ▁ líneas borradas.

TeclaAcción
]h / [hIr al cambio siguiente / anterior
gHghDeshacer el cambio de esta zona y dejarla como en el último commit
Espacio→g→dVer los cambios dentro del código (otra vez para ocultarlos)

LazyGit

Se abre con Espacio→g→g (Neovim), l desde el inicio, o Ctrl+a→g (tmux). Desde Neovim encuentra el repositorio aunque esté en una subcarpeta; si hay varios, pregunta cuál.

TeclaAcción
?Menú de ayuda contextual
Espacio (en archivos)Marcar / desmarcar para el commit (stage)
cHacer commit (con corrector ortográfico)
p / PPull / push
sStash
q / EscSalir / volver

Las teclas cambian de significado según el panel. Consulta ? antes de pulsar al azar en un repo importante.

10

Node, NPM y Vite

# ver versiones npm --version node --version # crear un proyecto Vite en el directorio actual npm create vite@latest . # ejecutar un script de package.json (ej. arrancar el proyecto) npm run dev

El símbolo ^ delante de una versión en package.json significa "esta versión o cualquier posterior compatible", no una versión fija. Para un archivo suelto .js o .ts basta con Espacio→r.
